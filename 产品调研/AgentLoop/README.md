## 模块总表

AgentLoop 以 **AgentSpace（智能体空间）** 为顶层资源边界，左侧导航 12 项分四组：

| 分组 | 模块 | 一句话 |
|---|---|---|
| — | **Agent 总览** | AgentSpace 着陆页，展示 Agent 核心指标、趋势与排行；未接入时作为产品闭环引导页 |
| — | **快速启动** | 把观测接入、效果评估、数据集构建、资产管理四条主线做成带耗时预估的引导清单，每步给出可复制命令 |
| 观测与审计 | **接入中心** | 全部 37 种接入方式的目录，选定后按参数自动生成安装命令与环境变量，是整个产品的数据入口 |
| | **AI Agent 可观测** | 观测主界面，含总览 / AI Agent / 全景拓扑 / 链路追踪 / 会话分析 / 聚类与归因 / 场景化分析 / 告警管理八个视角；实测该模块嵌自云监控 2.0 |
| | **仪表盘** | 自定义大盘列表，实体托管在云监控 2.0 工作空间，AgentLoop 只做入口 |
| | **审计** | 面向安全合规的独立视角，把工具调用与决策分支变成可追溯的风险事件与事实证据链；需独立接入日志数据源 |
| 评估与实验 | **数据中心** | 数据飞轮中枢：Trace 与 eBPF 日志清洗成 Trajectory，经 Pipeline 加工为可复用 Dataset；含 AI 助手 Loopie 生成管线 |
| | **评估** | 核心模块：定义评估器（21 个内置判官）、建评估任务（对哪批数据跑）、在分析洞察看分数分布与低分样本 |
| | **实验** | 受控对比不同模型 / Prompt / Agent 版本的效果差异，与评估共用评估器和数据集 |
| 持续优化 | **Agent 资产** | 把 Prompt 与 Skill 从代码里拆出来做版本化托管，实现「不重新部署即可发布新版本」，含 Latest/Production 双通道与安全扫描 |
| | **上下文工程** | 经验库 + 记忆库：从真实轨迹挖掘成功路径与失败模式，经 Recall Skill 在任务执行前召回注入，实现不改模型权重的自进化 |
| — | **系统管理** | AgentSpace 级配置中心：空间管理（含云资源绑定）、服务注册、额度配置、标注配置、标签管理 |

## 三个最值得记住的发现

1. **它不是自建存储的独立系统，而是架在阿里云既有产品之上的编排层。** 链路与轨迹存 SLS（Logstore `logstore-tracing` / `agent-trajectory` / `ebpf-event`），指标告警走云监控 2.0，Prompt/Skill 资产托管在 MSE AI 治理中心。控制台「空间管理」页把这些绑定资源直接列了出来。
2. **内置评估器实测 21 个，不是文档说的 13 个**；且分 `Agent`（Agent 节点执行，支持挂载 Skills/MCP 主动取证）与 `LLM`（纯 LLM 判分）两型，21 个里 18 个是 Agent 型。Session 级评估独立成组 6 个，与单轮评估平级。
3. **接入面按形态而非框架切分**：eBPF 无侵入 / LoongSuite Pilot 本地客户端 / 语言框架探针，三者可叠加，用「探针类型」字段区分 —— 与我们原型的「LoongSuite 三通道」同源。
