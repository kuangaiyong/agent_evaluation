## 这些文件是什么

- **是原文全文**：抓取原始页面 → 提取正文 → 转 Markdown。表格、数据、附录、评分指引、示例数据集、代码块都保留
- **不是解读或摘要**。每份文件开头只有一个来源信息块（原始链接、公众号/媒体、发布日期、抓取日期），正文之后不加评论
- 代码、SQL、JSON 结构与参考文献按惯例保留原文不译
- 随文图片一并抓到 [`assets/`](assets/)，按 `<编号>-<短名>/img-NN.<ext>` 存放，正文用相对路径引用，离线可读
- 版权归原作者及原媒体所有，此处仅供部门内部学习参考

## 抓取过程中遇到的问题

| 问题 | 处理 |
|---|---|
| 微信公众号原文（美团那篇）需过验证 | 用 arXiv 论文 + GitHub 仓库替代 |
| 微软 techcommunity 403 | 回溯到 microsoft.com 的一手博客，内容更全（含附录评分指引与示例数据集） |
| CSDN 转载 521 | 回溯到作者 Lun Wang 的个人博客原文，内容比转载丰富（含参考文献与 Schaeffer 的反方论证） |
| 公众号正文图片懒加载，`src` 是占位符 | 取 `data-src`，下载时带 `Referer` 头，否则 mmbiz.qpic.cn 返回 403 |
| 公众号代码块每一行是独立的 `<code>` 元素 | 逐个 `<code>` 取文本再按行拼接。只取第一个 `<code>` 会丢掉除首行外的全部代码（12 号文首次转换因此只剩 15% 正文） |
| 部分公众号不用 `<pre>`，而是给 `<section>` 套等宽字体的内联样式当代码块 | 按 `font-family` 是否等宽识别，含换行的转围栏代码块。不认这类节点，代码会被当正文转义，下划线变 `\_`、换行全丢（18、19 号文） |
| `**加粗：**中文` 在 CommonMark 里收尾星号不满足 flanking 规则，渲染成字面 `**` | 把标点挪到 `**` 外面；个别挪不动的改用 `<strong>`。字符本身不动，代码块内不动 |
