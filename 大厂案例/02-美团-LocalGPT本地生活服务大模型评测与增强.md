## 摘要

大语言模型（LLM）已展现出卓越的能力，并在多个领域取得重大突破，近年来被广泛采用。在此进展基础上，我们研究了它们在本地生活服务领域的潜力。在本研究中，我们建立了一个全面的基准，并系统评估了多种 LLM 在与本地生活服务相关的广泛任务上的表现。为进一步提升其效果，我们探索了两条关键路径：**模型微调**与**基于智能体的工作流**。我们的发现表明，**即便是一个相对紧凑的 7B 模型，也能达到与大得多的 72B 模型相当的性能水平**，有效地在推理成本与模型能力之间取得平衡。这一优化极大地提升了在真实线上服务中部署 LLM 的可行性与效率，使其对本地生活应用而言更加实用可及。

**关键词**：大语言模型；本地生活服务；有监督微调

## 1. 引言

大语言模型（LLM）在从对话式 AI 到数学问题求解等多个领域取得了显著成功。然而，尽管它们在通用任务上能力出众，LLM 在专业知识至关重要的领域特定应用中往往表现吃力。这一局限推动了面向特定领域的 LLM 的发展，例如医疗诊断、金融分析与代码生成。

**本地生活服务代表着一个规模巨大却未被充分探索的 LLM 应用机会。** 这类服务通过基于位置的供给满足用户的日常需求，例如餐饮、住宿、个人护理、教育与娱乐等。与传统电商不同，本地生活服务具有内在的复杂性：它们涉及**物理交互、时间约束、以及因地区与文化而异的本地化偏好**。设想一下，一位用户选择餐厅不仅取决于菜系偏好，还取决于时间、天气、交通状况、特殊场合等实时因素，甚至取决于逐街区变化的微妙文化语境。这些因素错综复杂的交织，为本地生活服务平台上的计算理解与决策带来了根本性挑战。

美团作为中国最大的本地生活服务平台，既体现了这一机会的规模，也体现了其中挑战的多样性。该平台需要在众多任务上具备精细的理解能力：解读商户信息与服务能力、分析用户偏好与行为模式、预测各种时空语境下的消费趋势、生成个性化内容、以及促进有效的用户—商户互动等等。每一项任务不仅需要从历史数据中做统计学习，还需要对人类行为、文化知识与情境理解进行常识推理。传统机器学习方法往往力有不逮，尤其是在**长尾场景**中，数据稀疏使纯统计学习失效。LLM 凭借其广博的知识基础与推理能力，提供了一个有希望的解法。然而，**两个关键缺口**阻碍了它们的有效部署：

- 第一，**不存在系统化的评测框架**来评估 LLM 在本地生活服务平台所需的多样任务上的表现。
- 第二，以网络为中心的训练数据与本地服务线下、位置特定的本质之间存在**领域漂移**，严重限制了通用 LLM；而领域特定指令数据的稀缺又阻碍了专用模型的开发。

在本文中，我们提出一个评估并增强本地生活服务平台 LLM 的框架。我们的方法通过系统评测与有针对性的模型改进来同时应对这两项挑战：

- 首先，我们引入 **LocalEval**，一个包含 **40 多项任务**、组织为**四大类**的综合基准：**服务基础、时空语境、用户交互、复合任务**。该基准使得对通用与领域特定 LLM 的严格评估成为可能。
- 其次，我们开发了一种**多智能体指令合成方法**，把原始平台数据转化为高质量训练样本，使更小的模型能够达到与大得多的模型相当的性能。
- 第三，我们为复杂的复合任务设计了**智能体式工作流**，融入专家知识以引导模型推理并生成额外的训练数据。

我们的实验表明，通过有针对性的指令微调，一个 7B 参数模型在本地生活服务任务上可以匹敌 72B 模型的表现，在保持效果的同时显著降低部署成本。此外，在美团推荐、搜索与评论排序系统中的真实部署，验证了我们方法的实际影响。

**本文的贡献有四点：**

- 据我们所知，**我们是首个提出系统性框架来评估并应用 LLM 于本地生活服务平台的工作**。
- 我们构建了一个全面的离线基准，用以评估各类开源与闭源 LLM 在本地生活服务上的表现。
- 我们提出一种**基于多智能体的领域特定指令数据合成方法**，使小型 LLM 能以极小的算力开销训练出与大规模 LLM 相当的竞争力。
- 在离线基准与线上场景上进行的大量实验，证明了所提框架与微调后领域增强 LLM 的有效性。

## 2. 方法

我们的方法包含三个主要部分。第一，为系统评估现有 LLM 在本地生活服务任务上的能力，我们开发了 **LocalEval** 基准。第二，我们设计了一套指令微调方法以增强 LLM 对本地生活服务的理解。对于基准中的复合任务，我们开发了智能体式工作流以更好地应对这些挑战。

*图 1. 方法总览。我们首先开发 LocalEval 基准，系统评估 LLM 理解本地生活服务的能力。基于多智能体协作方法，我们构建 LocalInstruction，通过微调增强 LLM 的服务理解能力。对于复合任务，我们实现专家智能体以进一步提升 LLM 的问题求解能力。*

### 2.1 基准

大语言模型近年来快速发展，在多个领域取得显著进步。凭借对日常生活知识的理解，LLM 在处理生活服务平台上与本地生活服务相关的任务方面具有潜力。然而，此前**并没有对 LLM 在本地生活服务领域能力的系统评估**。我们引入 LocalEval，一个用于评估 LLM 本地生活服务能力、并为未来迭代建立度量标准的基准。

在本地生活服务平台上，**所有事件都可以理解为用户与服务在特定时空语境中的交互**。遵循这一视角，我们把基准设计为四个任务类别：**服务基础、带（时空）语境的服务、用户—服务交互、复合任务**。

#### 2.1.1 服务基础

美团平台提供多样的本地生活服务，具有品类、品牌、功能、适用场景等各种特征。准确理解这些服务属性，是有效进行用户—服务匹配的基础。

本任务类别包括从服务描述中做传统的 **CPV（品类—属性—值）抽取**，即识别品类、有意义的属性及其取值。我们还考察模型对品类、属性与取值之间关系的理解，包括**适用性、相似性与互补性**。举例来说，后者包含这样的问题：属性"口味"是否适用于品类"医美"？或者在消费场景上，哪些品类与"KTV"互补？

**本类别包含 18 种任务类型，共 7002 道题。**

#### 2.1.2 带语境的服务

本地生活服务与线上购物有根本区别，因为它受时空约束——它们受营业时间、位置的限制，消费模式还受天气、季节与事件影响。例如，外卖在恶劣天气时达到高峰，而娱乐场所的客流则会减少。本类别通过两种任务类型评估 LLM 对服务固有时空属性的理解，以及时间因素如何影响服务消费：**分析时空属性**（例如合理的营业时间）与**考察外部因素导致的消费模式变化**。

**本类别包含 10 种任务类型，共 3618 道题。**

#### 2.1.3 用户—服务交互

本地生活服务的存在是为了服务用户。我们引入这一类任务，以评估 LLM 能否理解用户对本地生活服务的看法与偏好。任务包括：基于用户画像预测用户偏好、基于用户此前在平台上的行为（如搜索与点击）推断潜在的服务消费、从用户评论中抽取有价值的信息与整体态度。**我们并不聚焦于单个用户，而是强调理解平台用户群体如何看待服务。**

**本类别包含 10 种任务类型，共 3824 道题。**

#### 2.1.4 复合任务

在本类别中，我们设计了三项需要 LLM 整合多种能力的任务，分别对应三个潜在的线上应用场景：

- **推荐场景**：基于此前的行为序列、用户画像与时空语境预测用户消费。
- **搜索场景**：在给定模糊搜索查询、用户画像与时空语境的情况下预测用户消费。
- **内容营销场景**：基于用户画像识别用户最感兴趣的评论。这项任务不仅对优化评论展示有价值，还展示了 LLM 理解"什么内容能吸引不同画像用户"的能力，可以延伸到广告等更广的应用。

**本类别包含 3 种任务类型，共 1202 道题。**

#### 2.1.5 数据质量控制

我们基于美团平台上真实的服务商、用户与消费数据构建这四类问题。

- 对于**无需人工介入、可从数据分析中推导答案**的问题，我们确保分析基于足够的数据量与科学方法，以识别稳定趋势而非随机波动。例如，在构建关于雨天对服务消费影响的问题时，我们**至少分析 10 个雨天与 10 个晴天**，并平衡工作日与节假日。
- 对于**需要人工标注**的问题，例如判断用户评论是否包含服务商的推广内容，我们**至少雇用两名标注者，且只接受标注者达成一致的问题**。

所有数据使用均已获得用户明确授权。我们人工筛查并移除了服务描述与评论中任何可能具冒犯性的内容。

### 2.2 领域微调

本节介绍我们用于增强 LLM 理解本地生活服务能力的指令微调方法。我们的方法利用美团平台上积累的大量数据，包括商户的客观属性（如位置、营业时间）、自我描述、用户消费记录与评论。我们设计 **LocalInstruction** 来把这些平台数据转换成适合 LLM 学习的格式。

#### 2.2.1 数据来源

我们使用的原始数据包括：

- **商户数据**：商户名称；商户提供的信息，包括自我描述、位置、营业时间、品牌与品类。
- **用户数据**：用户授权的画像信息。
- **交互数据**：用户—服务交互记录，包含时间戳、位置，以及浏览、点击、下单等具体用户行为；用户产生的评论。

#### 2.2.2 模板智能体（Template Agent）

尽管平台包含丰富的数据，但要让 LLM 有效学习，需要适当的组织。我们的基本思路是设计问答模板来结构化这些信息。我们把客观信息维度提供给模板生成智能体，由它创建把信息组织成问答对的模板。

例如，给定商户名称、描述、自报经营品类这几类输入，模板智能体会生成如下模板：

> "**Instruction**：一家名为 {name} 的商户，其自我描述为 {introduction}，它的经营品类是什么？
> **Output**：该商户属于 {category}。"

为确保数据的多样性与覆盖度，我们设计了多种信息输入组合，并要求该智能体为每种组合**生成至少 10 个句式不同的模板**。我们对商户与用户采样，按这些模板组织其原始信息，形成 LocalInstruction 的第一部分。这种基于模板的方法能够高效、低成本地生成大规模训练数据。

#### 2.2.3 商户智能体与用户智能体

模板智能体虽能把原始平台信息结构化用于指令微调，但这种组织方式仅限于简单的信息拼接，**缺乏对多源信息之间内在关系的建模**。为解决这一局限，我们设计了基于 LLM 的**商户智能体（Merchant Agent）**与**用户智能体（User Agent）**，分别从商户与用户视角组织信息，用 LLM 在不同信息片段之间建立逻辑联系。

例如，商户智能体不仅能呈现商户的名称、描述与品类，还能基于商户名称与自我描述**为品类归类提供逻辑解释**。类似地，用户智能体既能陈述用户画像、时空语境与消费行为，也能基于用户画像与语境**解释驱动这些行为的潜在动机**。此外，借助 LLM 先进的推理能力，我们让这些智能体能够在原始数据之外做扩展与外推，探索商户功能、适合的消费场景、用户长期偏好与行为倾向等多个方面。

**商户智能体的运作示例：**

- **输入信息**：名称、简介、品类
- **LLM 生成的输出（商户视角）**："我是 {name}，{introduction}。我属于 {category}，因为 {LLM 生成的、把简介与品类联系起来的理由}。"

**用户智能体的示例：**

- **输入信息**：用户画像、购买记录（商户、时间、位置）
- **LLM 生成的输出（用户视角）**："我是一个画像为 {profile} 的用户。我在 {time} 于 {location} 去了 {merchant}，因为 {LLM 基于画像与语境生成的理由}。"

#### 2.2.4 交互描述智能体（Interaction Description Agent）

在平台上，用户与商户并非孤立存在，而是在特定时空语境中互动。理解本地生活服务，需要在个体属性之外理解这些交互模式。因此我们设计了交互描述智能体，通过生成交互数据来对用户—商户交互建模：

给定完整的用户信息、商户信息与消费语境，该智能体生成**模拟的对话往来**，其中包含潜在的心理活动、围绕用户需求与商户能力展开的对话历史、以及商户能力如何满足用户需求进而导向消费行为的完整过程。这一做法使 LLM 能够理解用户与商户属性如何影响具体的交互行为。

**示例：**

- **输入信息**：用户画像；商户详情（名称、简介、品类、位置、营业时间）
- **LLM 生成的输出（模拟交互）**："在 {scenario} 场景下，用户说：'X'。商户回复：'Y'。对话继续，用户说'Z'，最终促成了一次成功交易。"

#### 2.2.5 指令生成智能体（Instruction Generation Agent）

商户智能体、用户智能体与交互描述智能体生成的内容是纯文本而非问答对。我们设计了指令生成智能体，**把每段生成文本视作答案，反向生成可能的问题**，从而将数据转换为"指令—输出"格式以支持微调。

**示例：**

- **输入**："我是 {name}，{introduction}。我属于 {category}，因为 {LLM 生成的理由}。"
- **LLM 生成的指令**："名为 {name}、描述为'{introduction}'的商户属于什么品类，为什么？"
- **最终训练对**：
  - Instruction：上面 LLM 生成的指令
  - Output：原始的输入文本

#### 2.2.6 指令微调细节

我们采用 **Qwen2.5-72B 作为所有智能体的基础模型**。我们微调了多个已在通用领域数据上完成指令微调的开源模型，包括 Qwen2.5 系列的五个模型（0.5B、1.5B、3B、7B、14B）与 Llama3 系列的三个模型（Llama3.2-1B、Llama3.2-3B、Llama3.1-8B）。微调在一台配备 **8 张 A100 GPU** 的服务器上、使用 accelerate 以全量训练模式进行。

在实验过程中我们观察到：**相比训练数据质量，训练超参数对模型性能的影响要小得多。** 因此我们固定了训练超参数，把最优超参数的探索留给未来工作。核心超参数设置为：学习率 **6e-6**，每 GPU 批大小 **4**，梯度累积步数 **4**，训练轮数 **2**。按照常见做法，我们采用 cosine 调度器，并且**只在输出 token 上计算损失**。

### 2.3 构建专家智能体

通过指令微调，LLM 在通用的本地生活服务理解任务上展现出增强的能力。从更宏观的视角看，模型性能的提升不仅可以通过增加参数规模或参数优化来实现，也可以通过**测试时扩展（test-time scaling）**技术实现，例如思维链或智能体式工作流。为进一步增强模型能力，我们为与实际应用高度相关的复合任务设计了**专家智能体**。这些智能体利用微调后 LLM 的参数化记忆，并基于设计好的智能体式工作流完成任务。

三个复合任务的智能体式工作流如下：

**推荐。** 具体任务是：给定用户此前的行为序列、用户画像与时空语境，预测用户的消费行为。工作流为：识别具有相似画像与时空语境的用户的行为模式 → 通过此前的行为序列分析用户偏好与当前意图 → 结合用户画像与时空语境调整对用户意图的判断 → 做出预测。

**搜索。** 任务是：给定一个模糊的搜索查询、用户画像与时空语境，预测用户会点击哪个商户。工作流为：识别具有相似画像与时空语境的用户的行为模式 → 分析搜索查询以理解用户意图 → 结合用户画像与时空语境调整对用户意图的判断 → 预测将被点击的商户。

**内容营销。** 任务是：给定用户画像，判断哪条评论对用户最有意思。工作流为：识别相似画像用户的偏好 → 解析评论主题与情感倾向 → 评估评论质量 → 判定哪条评论对用户最有意思。

通过这些智能体式工作流生成的推理过程文本，连同其对应的问题，构成可用于训练模型的数据对，从而进一步提升模型在这些任务上的表现。**在理想情形下，随着模型性能提升，它会生成更高质量的数据；反过来，这些高质量数据又通过训练提升模型性能，形成数据飞轮效应。**

## 3. 实验

### 3.1 评测设置

### 3.4 跨城市评测

本地生活服务高度依赖位置。不同城市有各自的地理空间与用户生活方式，理解其本地生活服务需要不同的知识。在主实验中，基准与指令微调数据集主要使用来自**北京**的商户与用户行为数据。我们尝试为不同城市构建基准与指令微调数据集，以检验我们的指令微调方法能否增强 LLM 对不同城市本地生活服务的理解，并分析在一个城市数据上训练得到的能力能否迁移到另一个城市。

### 3.6 消融实验

我们通过移除每一类智能体生成的数据、观察对微调后模型性能的影响，进行了全面的消融实验，以验证 LocalInstruction 中每个智能体的数据是否都对最终性能有贡献。我们在 Qwen2.5-7B 与 Llama3.1-8B 上做实验。结果揭示：

**每一类智能体生成的训练数据在两个模型、所有任务类别上都是有效的。** 对两个模型与每个任务类别而言，移除任何一类训练数据都会导致性能下降，证明了我们方法中每个组件的有效性。

**商户智能体对「服务基础」类别最为关键。** 在两个数据集上，移除商户智能体对服务基础类别的负面影响最大，表明该智能体生成的数据对这一类别的提升贡献最显著。**这说明即便模板智能体已包含原始商户信息，通过 LLM 智能体的方式建立逻辑联系仍然重要。**

**交互描述智能体对「带语境的服务」与「用户—服务交互」两类最为关键。** 在两个数据集上，移除交互描述智能体生成的训练数据对用户—服务交互类别的负面影响最严重，其对带语境的服务的影响在所有数据类型中也是最大的。这说明**时空语境下的用户—商户交互数据，对 LLM 理解服务、用户与时空因素之间的关系至关重要。**

## 4. 部署与应用

微调后的大语言模型对美团业务运营展现出更强的理解，并能通过实际部署带来业务价值。下面介绍我们微调后模型在美团推荐、搜索与评论排序三个场景中的部署案例。需要说明的是，我们的模型具备本地生活服务任务的通用能力，这三个部署案例只用到了模型能力的一部分，还有很大空间可以探索其他应用。由于线上延迟约束，**我们主要的应用方式是预先为商户与评论计算标签或特征，再在线上算法中使用**。

### 4.1 推荐

用户访问本地生活服务平台是为了满足日常需求。每个商户都承担特定功能以满足特定用户需求。例如，高端牛排馆满足用户的浪漫约会需求，而中餐馆则满足聚餐需求。**原始商户数据并不直接提供这些对理解商户很重要的功能标签。** 我们使用在美团业务数据上训练的微调模型，基于商户名称、品类与自我描述文本生成商户功能标签。这些标签成为产品特征，基于标签的召回构成线上推荐模型召回源的一部分。

我们在美团首页推荐系统上做了 **7 天线上 A/B 实验**，评估加入模型生成的功能标签后的性能提升。

**表 6. LLM 生成的商户标签对美团线上推荐系统的增强**

| 品类 | PV | UV | OV | NCC |
|---|---|---|---|---|
| 到餐 | -0.09% | +0.00% | +0.33% | +1.49% |
| 娱乐 | +1.75% | +1.89% | +0.53% | +3.29% |
| 丽人 | -0.59% | +0.25% | **+4.73%** | +2.83% |
| 整体 | +0.34% | +0.21% | +0.27% | +0.15% |

表中 PV 指页面浏览量，UV 指独立访客数，OV 指订单量，NCC 指新客数。提升幅度指的是引入基于 LLM 功能标签的召回后，相对于不含该召回源的基线的性能提升。大多数指标都有提升，**其中直接影响平台收入的 OV 在所有品类上都有显著增长**。值得注意的是，在相对长尾的丽人品类上，把功能标签纳入商户建模带来了 **4.73% 的 OV 提升**，展示了 LLM 生成功能标签的高价值。

### 4.2 搜索

在搜索场景中，基于用户部分输入的内容推荐搜索关键词能提升用户体验。例如，如果用户想买酮康唑软膏，理想的关键词建议应当在只输入前几个字母后就出现。然而，有意义的搜索关键词数量庞大，人工定义耗费大量人力。因此我们用微调后的 LLM 从商品描述、品类与属性中生成潜在搜索查询，以补充人工定义的建议集。

在 **2024 年 7 月 19 日至 7 月 25 日**进行的线上 A/B 测试中：

**表 7. LLM 生成的搜索查询建议对美团线上搜索服务的增强**

| 指标 | Session-CTR | UV-CTR | 查询曝光 | 订单量 |
|---|---|---|---|---|
| 提升 | +0.48% | +0.44% | +0.33% | **+0.53%** |

结果显示关键的互动与转化指标都有稳定提升。用户与搜索建议的交互更频繁，体现为 Session-CTR 提升 0.48%、UV-CTR 提升 0.44%。最重要的是，这种增强的搜索体验转化为了业务影响——**订单量提升 0.53%**。

### 4.3 评论排序

对商品页展示的评论进行排序，有助于用户找到高质量、相关的评论内容。**值得信赖、有参考价值的评论应当具备**：有深度的文字内容、可付诸行动的建议、自然的语言表达、可信且吸引人的措辞、非推广性内容、以及非 AI 生成的内容。传统模型难以识别这些特征；我们用微调后的 LLM 在这些维度上给评论打分，作为评论特征。把这些特征纳入排序模型后，我们观察到评论互动与转化的显著提升。

在 **2025 年 1 月 18 日至 2 月 7 日**进行的线上 A/B 测试中：

- 平均评论浏览时长提升 **1.42%**
- 人均浏览评论数提升 **0.79%**
- 阅读过评论的用户的转化率提升 **0.27%**

总之，这三个场景上的实验表明，把我们微调后的 LLM 部署到本地生活服务平台的实际应用中具有很高的价值。

## 5. 相关工作

### 5.1 大语言模型及其应用

大语言模型经历了快速发展。自 GPT-3 通过规模化展示出强大的少样本学习能力以来，Claude-3.5 Sonnet、GPT-4 等更强大的模型在推理与知识整合方面表现卓越。这些模型在文本分析、数学推理与科学分析上表现出色。凭借这些多样能力，LLM 已成功应用于社会科学、自然科学、图学习、软件开发、医疗健康、城市科学与教育等多个领域。**尽管本地生活服务是影响数十亿用户日常生活的关键领域，关于如何应用 LLM 理解本地生活服务、帮助用户更好地与之互动的系统性研究仍是空白。** 我们的工作通过全面评估并改进 LLM 在该领域的能力，填补了这一研究缺口。

### 5.2 大语言模型的评测

大语言模型已成为通用模型，这促使人们通过多样的基准广泛评估其能力。这些评测涵盖基础语言理解、推理能力、领域知识与专业技能。此外，研究者还开发了评估常识理解、道德判断与深度思考等特定认知能力的基准。**然而，尽管本地生活服务在现代社会具有重大的经济与社会影响，此前并没有对 LLM 在这一关键领域能力的系统评估。** 我们的工作通过引入 LocalEval——首个评估 LLM 本地生活服务能力的综合基准——填补了这一空白。

### 5.3 大语言模型智能体

大语言模型具备广泛的通用能力。在把 LLM 应用于下游任务时，构建 LLM 智能体被证明是有益的，因为智能体范式提供了优化的问题求解工作流，同时支持外部记忆与工具集成。LLM 智能体已在代码生成、文本分析、推荐系统、具身智能、社会模拟与城市科学等多个领域取得优异成果。近期一些工作也利用智能体生成指令微调数据，其中智能体工作流确保了高质量的数据生成，而使用多样智能体作为生成种子则保证了数据的多样性。受这两条工作路线的启发，在我们的方法中，我们既利用智能体生成用于微调 LLM 的指令微调数据，也设计智能体式工作流帮助 LLM 更好地解决复杂问题。

## 6. 结论

在本文中，我们引入了一个评估并增强本地生活服务平台大语言模型的框架。我们开发了一个包含 **40 多项任务**的综合基准，并提出了一种**基于多智能体的指令微调方法**，使 7B 参数模型能够取得与 70B 参数模型相当的竞争力。通过大量实验以及在美团推荐、搜索与评论排序场景中的真实部署，我们证明了该框架在广泛任务上的有效性。我们的工作为开发和评估面向本地生活服务平台的领域特定 LLM 奠定了基础。
